# What the compiler says

Every message the compiler prints for a refused spelling, one row per spelling. The check column is the entry in [checks.md](checks). The page is generated by `DiagnosticCatalogTest` from the specs under `compiler/src/test/resources/diagnostics/`, and that test fails when a message changes until the page is regenerated and the change reviewed.

| V4 | `after commit` with no guard and no backup schedule. | `[V4] rule 'Confirm' fires 'after commit', in a transaction of its own, so a firing can be lost between the commit and the rule, and nothing would find it; trigger the rule on a guard, a condition its body makes false by creating a record or setting a field, and add a backup schedule beside 'after commit' (Reference §18)` |
| V4 | `after commit` with a guard but no backup schedule. | `[V4] rule 'Apply' fires 'after commit' with a guard but no backup schedule, so a lost firing would never be retried; add a schedule beside it, 'after commit, Hourly' (Reference §18)` |
